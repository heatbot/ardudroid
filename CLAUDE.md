# Working preferences

## Pine Script output

- Whenever you write or change Pine Script (TradingView) code, also publish the complete script as an Artifact page with a one-click **Copy** button, so it can be pasted straight into the TradingView Pine Editor.
- Show the full script on the page (not a diff or excerpt), with the indicator name, Pine version and a short "paste into Pine Editor → Add to chart" note.
- Republish to the same artifact when the same script changes, so the link stays stable.
